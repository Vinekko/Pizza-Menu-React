# 🍕 Vincenzo's Pizzeria

> **Auténtico Sabor Italiano en cada Rebanada**

Bienvenido al repositorio oficial del menú digital de **Vincenzo's Pizzeria**. Esta aplicación web moderna y reactiva muestra nuestra selección de pizzas artesanales, destacando la calidad de nuestros ingredientes y la pasión por la cocina tradicional.

---

## ✨ Características Principales

*   **Diseño Responsivo**: Adaptado perfectamente para móviles, tablets y escritorio.
*   **Interfaz Dinámica**: Renderizado eficiente de listas de productos utilizando React.
*   **Arquitectura de Componentes**: Código modular y mantenible.
*   **Estilo Estético**: Diseño visual atractivo que refleja la identidad de la marca.

## 🚀 Comenzando

Sigue estas instrucciones para obtener una copia del proyecto y ejecutarlo en tu máquina local.

### Prerrequisitos

*   Node.js actual
*   npm (incluido con Node.js)

### Instalación

1.  **Clona el repositorio**
    ```bash
    git clone <URL_ DEL_REPOSITORIO>
    ```
2.  **Instala las dependencias**
    Navega al directorio del proyecto y ejecuta:
    ```bash
    npm install
    ```
3.  **Inicia el servidor de desarrollo**
    ```bash
    npm run dev
    ```

```text

```
